CAREFLOW OPD — QUICK START IN VISUAL STUDIO CODE

1. Extract the complete ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select this extracted project folder.
4. Install the VS Code extension "Live Server" by Ritwick Dey.
5. Open index.html, right-click in the editor, and choose "Open with Live Server".
   Alternatively, click "Go Live" in the bottom status bar.
6. Your browser opens the website. Save edits in VS Code to refresh the page.

NO BUILD TOOLS OR PACKAGE INSTALLATION IS REQUIRED.

You can also double-click index.html after extraction. Keep index.html,
styles.css, and script.js together in this folder.

Single-file fallback: open CareFlow_OPD_Standalone.html directly.
